# Reader

Читалка `.epub` в браузере: загружаешь свои книги, собираешь их в коллекции,
публикуешь в общий каталог и читаешь — позиция, тема и размер шрифта сохраняются.

| | |
|---|---|
| [`BE/`](BE) | Bun + Elysia + Prisma + PostgreSQL, хранилище файлов локально или в Supabase |
| [`FE/`](FE) | Vite + React + TypeScript + Tailwind, читалка на epub.js |

## Быстрый старт

```bash
docker compose -f BE/docker-compose.yml up -d
```

```bash
cd BE && cp .env.example .env && bun install && bunx prisma migrate deploy && bunx prisma generate && bun dev
```

```bash
cd FE && cp .env.example .env && bun install && bun dev
```

Фронтенд — <http://localhost:5173>, API — <http://localhost:3000>, Swagger — <http://localhost:3000/swagger>.

Подробности в [BE/README.md](BE/README.md) и [FE/README.md](FE/README.md),
разбор вайрфреймов и решений — в [PLAN.md](PLAN.md).

## Экраны

- **Home** — свои книги, поиск, фильтры по жанру и избранному; второй таб — коллекции,
  где книги внутри каждой листаются вбок
- **Library** — общий каталог секциями: «Most popular» и дальше по жанрам
- **Upload** — два шага: файл, затем метаданные (они читаются из самого `.epub`) и `privat ⟷ public`
- **Книга** — обложка, жанры, прогресс, меню «…»: сменить обложку и название,
  добавить в коллекцию, опубликовать, убрать из библиотеки
- **Читалка** — постраничный режим, оглавление, светлая/сепия/тёмная тема, размер шрифта
- **Профиль** — статистика, тема интерфейса, выход

## Что стоит знать

Публикация книги необратима: `PATCH /book/:id` с `visibility: PRIVATE` для уже
публичной книги отвечает 403 — её могли добавить к себе другие читатели.

Коллекции ссылаются на `UsersBooks`, а не на `Book`, поэтому в коллекцию нельзя
положить чужую книгу, а удаление книги из библиотеки убирает её из всех коллекций.

По умолчанию файлы складываются в `BE/storage/` и раздаются самим API: обложки —
открыто, книги — только по подписанной ссылке на час. Для Supabase достаточно
задать `SUPABASE_*` в `BE/.env`.
