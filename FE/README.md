# Reader — фронтенд

React + TypeScript на Vite. Читалка .epub работает целиком в браузере через `epub.js`.

## Запуск

```bash
cp .env.example .env      # VITE_API_URL, по умолчанию http://localhost:3000
bun install
bun dev                   # http://localhost:5173
```

Бэкенд должен быть поднят — см. `../BE/README.md`.

## Структура

```
src/
├── shared/
│   ├── api/          клиент fetch + модули auth / books / collections
│   ├── lib/          чтение метаданных .epub, форматирование, debounce
│   ├── ui/           Button, Field, Modal, Cover, Shelf, Chip, Toast…
│   └── types.ts      типы, повторяющие DTO бэкенда
├── features/
│   ├── auth/         AuthProvider, вход и регистрация, ProtectedRoute
│   ├── home/         экран Home: табы All books / Collections
│   ├── library/      экран Library: каталог секциями по жанрам
│   ├── books/        карточка книги, меню «…», хуки TanStack Query
│   ├── collections/  таб коллекций и страница одной коллекции
│   ├── upload/       загрузка в два шага
│   ├── reader/       читалка на epub.js
│   └── profile/      профиль, тема интерфейса, выход
└── layouts/          AppLayout: таб-бар на телефоне, сайдбар на десктопе
```

## Как всё устроено

**Авторизация.** JWT лежит в `localStorage`. При старте токен проверяется через
`GET /auth/me`, а не принимается на веру. Любой ответ 401 чистит токен и возвращает
на экран входа.

**Загрузка.** Название, автор, язык и обложка читаются из `.epub` прямо в браузере
(`shared/lib/epub.ts`) и подставляются в форму — бэкенд файл не разбирает.

**Читалка.** Файл скачивается целиком по подписанной ссылке и отдаётся в `epub.js`
как `ArrayBuffer`: ссылка живёт час, а по частям epub.js упирался бы в истёкшую подпись.
Позиция сохраняется с задержкой 1,5 секунды после перелистывания, а также при уходе
со страницы и при закрытии вкладки.

**Вес бандла.** `epub.js` с `jszip` тянет около 400 КБ, поэтому и читалка, и разбор
метаданных грузятся динамическим `import()` — в основной бандл они не попадают.

## Палитра

«Spring Green Harmony» — десять шагов от тёмно-зелёного к жёлтому, объявлены
токенами `--color-brand-*` в `src/index.css`. Тёмный конец держит хром приложения,
светлый работает акцентом. Тёмная тема переключается в профиле.
